# tt_um_davieslennox0_gc012

A Tiny Tapeout project directory generated by [Forgeout](https://github.com/davieslennox0/tapeout-forge) (`forge export-silicon`) from an optimized NAND netlist for FabX task **GC-012**, a 4-to-2 one-hot encoder with error detector: 4 inputs, 4 outputs, purely combinational (no latches).

**Tapeout-ready export. We have not ordered fabrication. Ordering is a separate paid step that the circuit owner completes on Tiny Tapeout. We do not claim a physical chip exists.**

## What this repository is

- The generated Verilog is `src/tt_um_davieslennox0_gc012.v` (wrapper in the Tiny Tapeout `ttsky` shape; unused pins tied low).
- It is used to check that the netlist can be mapped through the open-source Tiny Tapeout flow (GitHub Actions: synthesis, place and route, DRC precheck). It is a feasibility check, not a submission.
- `test/` holds a cocotb RTL test whose expected outputs are the 16 distinct input/output pairs of the task's published test vectors.

## Results of the CI flow (see the Actions tab)

- `gds` and `precheck` succeed: 34 cells, about 173.9 square micrometres of synthesized cell area, 15 of 15 precheck checks.
- `viewer` fails because GitHub Pages is not enabled on this repository; it is a cosmetic deploy step.
- The GDS file's bytes differ between runs of the same Verilog, so no GDS hash is promised here.

## Status

The status of this design never exceeds "exported". It has not been submitted to any shuttle, paid for or fabricated.
